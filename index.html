What can I import and export?

ZipBatch supports CSV and XLSX files for supported Shopify product, variant and inventory data workflows. The options available inside the app depend on the connected store permissions and the feature set of the installed version.

Do I need Shopify Plus?

Core product and inventory workflows are designed for Shopify stores with the necessary API permissions. Some individual capabilities can vary by plan, store configuration or Shopify API eligibility.

Can I use a CSV with different column names?

ZipBatch includes column mapping for supported fields, helping you match spreadsheet columns to the relevant Shopify data without renaming every header first.

How do subscriptions work?

ZipBatch offers Starter at $10/month and Pro at $15/month. Subscription approval, renewals and cancellation are handled through Shopify's app billing system. Starter includes 50 jobs per month; Pro includes unlimited jobs subject to fair use.

Where can I get support?

Visit our support page for setup guidance, troubleshooting and a direct email contact. Never include access tokens, passwords or payment card information in support messages.

Getting started

After installing ZipBatch through Shopify, open the app from your Shopify admin. Choose the import or export workflow appropriate to the task. The options shown depend on your app permissions and active plan.

Before a large update: export or otherwise back up any critical product or inventory records, and test the workflow with a small sample first.

Import a CSV file

1

Select Import CSV

Choose the available Shopify resource or import workflow.

2

Choose your file

Upload your CSV and review how the app has read headers and rows.

3

Map the fields

Match source columns to supported destination fields. Confirm how existing records are identified or updated.

4

Run and verify

Start the job, review the outcome and check a sample of changed records inside Shopify.

Export Shopify data

Choose Export CSV, select the supported type of data and any available options, then run the export. Once the job completes, use the app's result/download control to obtain the file. Review exported columns before using the file in another system.

Working with column mappings

When your CSV uses custom headings, use the mapping screen to link them to supported Shopify fields. Keep values consistent: SKUs should identify the intended variant; location-specific quantities require a correctly selected location; and product status fields must contain supported values.

Where the app provides saved templates, use them for repeat files that follow the same column layout. Recheck a template after changing the structure of your source export.

Troubleshooting and safer imports

  • Keep the original CSV before submitting a large update.
  • Try a small test file with representative rows first.
  • Use consistent column names and values within one CSV.
  • Inspect validation messages rather than repeatedly retrying a failing job.
  • Avoid processing the same update simultaneously in multiple jobs.
  • If Shopify data doesn't look right, pause further imports and contact support.
